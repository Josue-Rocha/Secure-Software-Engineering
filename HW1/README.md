# Secure-Software-Engineering

## Getting Started
To get a local copy up and running, you just need to ensure that you have levenshtein and request modules downloaded. 

### Running the program



1. Install dependencies
     ```pip3 install -r requirements.txt```
2. Ensure that you're in the same directory as main.py

3. Type the command to run main.py
    Either
    ```python main.py detect /path/to/pom/files```
    Or
    ```python main.py all /path/to/pom/files```
